# Changelog

## 0.1.0 - Unreleased

- Add Lua, public C, Dynamic Hermes JSI, Static Hermes, and HTML5 WebTransport
  surfaces for sessions, streams, datagrams, closure, and backpressure.
- Add content-addressed native libraries for Defold's desktop, mobile, and
  Android targets.
- Support the current WebTransport `datagrams.createWritable()` API with the
  legacy `datagrams.writable` shape retained as a compatibility fallback.
- Include extension and third-party license notices in the deterministic ZIP.
